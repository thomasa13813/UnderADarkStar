These are the default keys. You can rebind them in **Settings**.

## Mouse

| Action                         | What it does                                                                        |
| ------------------------------ | ----------------------------------------------------------------------------------- |
| Left click                     | Attack the tile, or open the menu, depending on your "action on left click" setting |
| Right click (touch on mobile)  | Open the radial menu (see [[interface#radial-menu]])                                |
| <kbd>Shift</kbd> + left click  | Attack, when left click is set to open the menu                                     |
| <kbd>Ctrl</kbd> + left click   | Open the build menu (<kbd>⌘</kbd> on a Mac)                                         |
| <kbd>Alt</kbd> + left click    | Open the emote menu                                                                 |
| Middle click                   | Upgrade the nearest building automatically                                          |
| <kbd>Shift</kbd> + mouse wheel | Decrease or increase the attack ratio                                               |
| <kbd>Shift</kbd> + drag        | Select several Destroyers and Armies                                                |
| Mouse wheel                    | Zoom                                                                                |

## Keyboard

| Key                                                 | What it does                                                          |
| --------------------------------------------------- | --------------------------------------------------------------------- |
| <kbd>Esc</kbd>                                      | Close a menu, or cancel a build preview                               |
| <kbd>Enter</kbd>                                    | Build the unit under the cursor                                       |
| <kbd>Space</kbd>                                    | Alternate view (terrain / territories)                                |
| <kbd>M</kbd>                                        | Toggle the coordinate grid                                            |
| <kbd>U</kbd>                                        | Swap a Nuclear or Antimatter Warhead's arc direction                  |
| <kbd>C</kbd>                                        | Center the camera on your territory                                   |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | Move the camera                                                       |
| <kbd>Q</kbd> / <kbd>E</kbd>                         | Zoom out / in                                                         |
| <kbd>T</kbd> / <kbd>Y</kbd>                         | Decrease / increase the attack ratio                                  |
| <kbd>B</kbd>                                        | Send a fleet to the tile under the cursor                             |
| <kbd>G</kbd>                                        | Ground attack on the tile under the cursor                            |
| <kbd>Shift</kbd> + <kbd>R</kbd>                     | Retaliate against your most recent attacker (only while under attack) |
| <kbd>K</kbd>                                        | Request an alliance with the player under the cursor                  |
| <kbd>L</kbd>                                        | Break the alliance with the player under the cursor                   |
| <kbd>F</kbd>                                        | Select all your Destroyers                                            |
| <kbd>P</kbd>                                        | Pause or resume (solo games)                                          |
| <kbd>,</kbd> / <kbd>.</kbd>                         | Game speed down / up (solo games)                                     |
| <kbd>Alt</kbd> + <kbd>R</kbd>                       | Reset graphics                                                        |
