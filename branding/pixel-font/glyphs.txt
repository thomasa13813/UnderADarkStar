; DarkStar Pixel: the glyph source for the game's pixel face.
;
; Each glyph is a [c] header line naming its character, then its rows:
; '#' is ink, '.' is empty. Every row of a glyph has the same width.
; Rows 1-9 are the cap height and sit on the baseline; a 10th row, if
; present, hangs below it (the comma's tail). Strokes are 2 pixels.
; Lowercase letters reuse the capitals. Lines starting with ';' are comments.
;
; The first 20 letters were drawn for the title and buttons (2026-10-09..12);
; the rest were added to match on 2026-10-24.
;
; Rebuild with scripts/pixel-font/build.py (see scripts/pixel-font/README.md).
